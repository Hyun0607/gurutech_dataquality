stdtool 표준화 점검 프로그램 — 설치·사용 안내
====================================================

1. 설치
  - 받은 zip 파일을 원하는 곳(예: 바탕화면, 문서)에 압축 풀기 합니다.
    'C:\Program Files' 안에는 풀지 마세요 (쓰기 권한 문제).
  - 풀린 stdtool 폴더 안의 stdtool.exe 를 더블클릭하면 실행됩니다.
  - 파이썬, MySQL 등 따로 설치할 것은 없습니다.
  - 바탕화면 바로가기가 필요하면: stdtool.exe 오른쪽 클릭 → '바로 가기 만들기' → 바탕화면으로 옮기기.

  처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
  → '추가 정보' → '실행' 을 누르세요. (회사에서 만든 프로그램이라 서명이 없어서 뜨는 안내입니다)

2. 처음 설정 (왼쪽 아래 '설정' 버튼)
  - 제정일자: 기관 표준 제정일자를 고릅니다.
  - 산출물 폴더: 결과 파일이 만들어질 폴더 (기본: 바탕화면).
  - 표준 사전 → '사전 파일' 이 골라져 있으면 그대로 둡니다.
  - 공유 폴더: 관리자가 알려 준 팀 공유 폴더를 넣으면, 새 사전이 나왔을 때 켤 때마다 알려 줍니다.

3. 사용
  ① '메타 파일' 의 '찾기' 로 메타데이터 표준 관리항목 엑셀을 고릅니다.
     (탐색기에서 파일을 프로그램 창에 끌어다 놓아도 됩니다.)
     기관·시스템은 파일의 기관명·정보시스템명으로 자동으로 정해집니다.
     (한 시스템에 DB가 여러 개라 못 정하면 '기관·시스템' 을 눌러 DB를 고르라고 알려 줍니다.)
  ② ▶ 실행 을 누릅니다. 끝나면 왼쪽 메뉴에서 지표별 결과를 봅니다.
  - 결과 파일은 산출물 폴더 아래 '기관_시스템' 폴더에 만들어집니다.
    (표준_구조_연계 / 수동등록 폴더, 실행기록.xlsx)

4. 회차 기록
  - 표준 정의 화면 맨 위 '기관표준 점검 · A값': 고른 기관의 기관표준으로 A값(1 / 0.9 / 0.8)과 깎인 이유를 보여 줍니다.
    통합시스템에서 내려받은 기관표준 엑셀(용어·단어·도메인·코드)을 [기관표준 파일 넣기]로 넣어도 됩니다.
    점검결과가 든 파일이면 실제 A값, 등록 양식이면 예상 A값입니다.
  - 사전에 그 기관의 기관표준이 있으면(지금은 충청남도 계룡시·예술경영지원센터) ▶ 실행 때 기관표준을 자동으로 준용합니다.
  - 실행할 때마다 '회차 기록' 에 결과가 쌓입니다. 두 회차를 골라 고쳐진 오류·새로 생긴 오류를 볼 수 있습니다.

  예방적 품질관리 (왼쪽 메뉴, 메타 파일과 상관없음)
  - 대상 사업: 사업단이 보낸 '이행점검(N차) 대상.xlsx' 를 창에 끌어다 놓으면
    우리 관리 기관 사업만 골라 단계·사업유형·대응 지표, 다음 회차 완료 전환 예상, 내년 후보를 보여 줍니다.
    사업유형·금액·이관 칸은 두 번 눌러 고칠 수 있습니다.
    IRM에서 내려받은 '사전협의(총괄) 목록' 엑셀을 넣으면 사업단 목록이 나오기 전에
    발주·완료단계 대상과 1차·2차·내년을 먼저 예측합니다.
  - 발주단계 점검: 사업을 고르고 RFP(hwpx·hwp)를 끌어다 놓으면 빠진 데이터 요구사항과 넣을 문안을 보여 줍니다.
  - 완료단계 점검: 완료·감리보고서(pdf·hwpx·hwp)를 끌어다 놓으면 빠진 지표를 알려 줍니다.
  - 발주·완료단계 점검의 '결과 엑셀 저장' 은 사업단 이행점검 결과와 같은 양식으로
    지표별 점검 완료 / 보완 필요와, 보완할 지표마다 어떻게 보완할지(넣을 RFP 문안, 낼 산출물)를 적어 줍니다.
  - 같은 기관이면 발주·완료단계 점검 결과가 한 결과 엑셀에 모입니다.
  - 완료단계 점검의 '가이드 폴더 만들기' 는 보완이 필요한 지표만 폴더를 만들어 가이드·인정 산출물 안내·사업단 예시를 넣어 줍니다.

5. 새 사전 / 새 버전
  - 새 사전: 공유 폴더에 새 사전이 있으면 켤 때 "받을까요?" 라고 묻습니다. '예' 를 누르면 됩니다.
    공유 폴더가 없으면 관리자에게 받은 .sqlite 파일을 설정 → 표준 사전 → '다른 파일로' 로 넣습니다.
  - 새 버전: 프로그램을 끄고, 새 zip을 같은 곳에 풀어 stdtool 폴더를 덮어씁니다.
    설정·사전·회차 기록은 사용자 폴더(%APPDATA%\stdtool)에 있어서 그대로 남습니다.

6. 자주 나는 문제
  - "파일을 쓸 수 없습니다": 산출물 엑셀을 열어 둔 상태입니다. 엑셀을 닫고 다시 실행하세요.
  - "표준 사전을 읽지 못했습니다": 설정 → 표준 사전에서 '사전 파일' 이 골라져 있는지 보고,
    안 되면 관리자에게 사전 파일(.sqlite)을 받아 '다른 파일로' 로 넣으세요.
  - 기관·시스템 목록이 비어 있음: 사전 파일에 평가대상 DB 목록이 없는 경우입니다. 관리자에게 새 사전을 받으세요.

메타 파일에는 개인정보가 있을 수 있습니다. 프로그램은 메타 파일을 각자 PC에서만 읽고,
사전 파일·공유 폴더·회차 기록에는 메타 파일 내용을 남기지 않습니다 (파일 이름만 남김).
